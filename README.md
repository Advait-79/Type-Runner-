# 🏃 Type Run

A Java-based typing game where your typing speed controls how fast your
character moves.

## 🎮 How It Works

The player is given a random string and must type it as quickly as possible.

- ⚡ Faster typing → Higher score
- 🏃 Faster typing → Greater character movement
- ❤️ Player starts with 3 lives
- 📈 Word length increases every 5 successful attempts
- 💀 Game ends when all 3 lives are lost
